# Mini-Shell: 系統程式期中專案與學習筆記 (與 AI 助理 Gemini 協作開發)

## 專案簡介
本專案為「系統程式 (System Programming)」課程的期中作業。目標是透過 C++ 實作一個輕量級的命令列直譯器 (Mini-Shell)，藉此深入理解 Linux 作業系統底層的行程管理 (Process Management) 與系統呼叫 (System Calls)。

本專案採用「人機協作」的模式完成。由我主導專案方向、架構設計與環境測試，並透過與 AI 助理 Gemini 的討論來加速程式碼的生成、除錯以及核心概念的釐清。

## 核心學習目標與使用的 System Calls
在這個專案中，我學習並實作了以下幾個關鍵的作業系統概念：

1. **行程建立 (`fork`)：** 
   - 了解如何從當前的父行程中複製出一個完全相同的子行程。這對於理解作業系統如何實現多工處理非常重要。
2. **程式載入與執行 (`execvp`)：**
   - 學習在子行程中，將原本的程式記憶體空間替換為新的程式碼並執行（例如執行 `ls` 或 `pwd` 指令）。
3. **行程同步 (`waitpid`)：**
   - 讓父行程（也就是這個 Shell）暫停，直到子行程執行完畢再繼續給出 `myshell>` 提示字元。同時也學到這可以避免產生「殭屍行程 (Zombie Process)」。
4. **目錄切換 (`chdir`)：**
   - `cd` 指令無法透過 `fork`+`execvp` 執行，必須在 Shell 內部直接呼叫 `chdir` 系統呼叫來改變當前行程的工作目錄。
