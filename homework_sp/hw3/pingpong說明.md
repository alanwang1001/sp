# 🏓 桌球數據追蹤器 (Ping Pong Tracker)

這是一個輕量級的 Python 命令列工具，專門用來記錄桌球對戰比分，並自動計算各選手的參賽次數與勝率。

## ✨ 功能特色

* **快速記錄比賽**：輸入雙方玩家姓名與分數，系統會自動判定勝負。
* **勝率自動計算**：依據歷史對戰紀錄，統計每位選手的「參賽場次」、「勝場數」以及「勝率」。
* **本地端資料保存**：對戰紀錄會自動儲存為 `pingpong_data.json`，關閉程式後資料不會遺失。

## 🚀 系統需求

* **Python 3.x**：本程式僅使用 Python 內建模組，不需安裝任何第三方套件。

## 🛠️ 使用方式

1. 將程式碼存檔為 `tracker.py`。
2. 開啟終端機（或命令提示字元、PowerShell），切換到程式所在的資料夾。
3. 執行以下指令啟動程式：

   ```bash
   python tracker.py
